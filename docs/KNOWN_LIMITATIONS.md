# Known Limitations

This version is an MVP foundation and requires environment-specific testing before production use.

- Returned/recalled document editing and full resubmission still require a dedicated edit screen.
- Due dates use calendar days; public holidays and working-day calendars are not included.
- Notifications are in-app only; email, SMS and push delivery are not included.
- Image capture does not include cropping, perspective correction or OCR.
- Formal organisation-specific printable reports are not yet defined.
- Production deployment still requires HTTPS, secure-cookie configuration, backup, retention, antivirus scanning and a security review.
- Remote Oracle connectivity, filesystem permissions and multi-user concurrency must be tested in the target office environment.
